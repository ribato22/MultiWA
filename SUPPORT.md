# Support

Thanks for using MultiWA! Here's how to get help.

## Questions & how-to

- **Documentation** — start with the [`docs/`](./docs) guides and the
  [README](./README.md) quick start.
- **API reference** — the running server serves Swagger UI at `/api/docs`.
- **Discussions** — ask usage questions in
  [GitHub Discussions](https://github.com/ribato22/MultiWA/discussions) (if
  enabled) rather than the issue tracker.

## Bugs & feature requests

- Search [existing issues](https://github.com/ribato22/MultiWA/issues) first.
- File a [bug report](https://github.com/ribato22/MultiWA/issues/new?template=bug_report.md)
  or [feature request](https://github.com/ribato22/MultiWA/issues/new?template=feature_request.md)
  with the template.

## Security

**Do not** open a public issue for security vulnerabilities. Follow
[SECURITY.md](./SECURITY.md) for private disclosure.

## Contributing

See [CONTRIBUTING.md](./CONTRIBUTING.md) for the development setup, branch
conventions, and PR process.

## Scope of support

MultiWA is community-maintained open-source software provided as-is under the
MIT license. There is no SLA. Response times depend on maintainer availability.
