Get Started in Seconds

Four commands. That's all it takes.

Terminal 
# Clone the repository
git clone https://github.com/ribato22/MultiWA.git
cd MultiWA

# Configure and run
cp .env.docker .env
docker compose up -d

# 🎉 Done! Access:
# Admin Dashboard → http://localhost:3001
# API Swagger     → http://localhost:3333/api/docs
